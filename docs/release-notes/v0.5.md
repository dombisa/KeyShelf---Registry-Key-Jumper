## Key Shelf Reg Jumper v0.5

Файлы: `KeyShelfRegJumper_x64.exe` / `KeyShelfRegJumper_x86.exe` — оконная версия для 64- и 32-битной Windows; `KeyShelfRegJumper_cli_x64.exe` / `KeyShelfRegJumper_cli_x86.exe` — консольная версия для скриптов (оболочка дожидается завершения, вывод не смешивается с приглашением). Контрольные суммы — в `SHA256SUMS.txt`.

### Новое
- **Держать от изменений** (вкладка «Защита», `/hold`): список веток (вся ветка или только сам ключ). При изменении или удалении программа возвращает исходное состояние и пишет в лог: что изменилось, на что, и что возвращено. Автозапуск при старте — по желанию.
- **Правка в текстовом редакторе** (`/open`, `/open-notepad`, `/open-with`, меню «Ветка»): ветка выгружается в `Saved\tmp`, оригинал сохраняется рядом (`*.orig.reg`); после правки — «Восстановить в реестр» или `/import`. Папка `tmp` очищается при выходе (настройка).
- **Экспорт в `.vbs`** наравне с `.bat` (имена `NO-…` / `NW-…`).
- **Командная строка**: справка `/?`, вывод в консоль (CMD, PowerShell, BAT, SSH; перенаправление работает), режим `/nogui` и `/noui` без окон, `/jump`, `/jumpm`, `/goto`, `/add`, `/list`, `/addreg`, `/export`, `/saveto`, `/bat`, `/vbs`, `/export-bat`, `/export-vbs`, `/snap`, `/snaps`, `/cmp … current`, `/watch` (события в консоль в реальном времени, между ними пустая строка), `/hold`, `/open*`, `/import`, `/clean-tmp`, `/probe`, `/log on|off`, `/cfg`, `/yes`. Коды выхода: 0 — успех, 1 — ошибка, 2 — неверные параметры, 3 — не найдено.
- В «Ветка из regedit» (`Ctrl+G`) добавлены действия «Держать от изменений» и «Править в Блокноте».

### Важно
- Для веток HKLM защита и импорт правок требуют прав администратора; права доступа (ACL) к веткам не восстанавливаются.
- Файлы не имеют цифровой подписи (SmartScreen или антивирус могут показать предупреждение). Разработка и проверка велись в основном в Wine; на реальных Windows 7–10 проверено ограниченно. Об ошибках сообщайте в Issues, приложив последние строки `keyshelf.log`.

## Key Shelf Reg Jumper v0.5 (English)

**New:** "hold from changes" (automatic restore of protected keys, with a log), editing keys in a text editor with the original kept for rollback, `.vbs` export alongside `.bat`, and a full command line (`/?`, console output, `/nogui`, jump/bookmarks/export/snapshot/compare/watch/hold/edit/import commands, exit codes 0/1/2/3). A console build (`KeyShelfRegJumper_cli_*.exe`) is provided for scripts.
Unsigned executables; mostly tested under Wine, limited testing on real Windows. HKLM protection requires administrator rights.
