## KeyShelf v0.2

Портативная программа для Windows 7–10: закладки на ветки реестра, переход в regedit, сохранение веток в `.reg`, экспорт в `.bat`.

**Файлы:** `KeyShelf_x64.exe` — для 64-битной Windows, `KeyShelf_x86.exe` — для 32-битной. Контрольные суммы — в `SHA256SUMS.txt`.

### Что внутри
- Закладки с вложенными папками и комментариями, переименование (`F2`), перетаскивание мышью
- Переход в regedit, в том числе в отдельном окне (`/m`); просто открыть regedit
- Добавление веток из `.reg` (меню, перетаскивание файла, пункт в контекстном меню `.reg`)
- Сохранение веток в `.reg` с датой, временем и своей заметкой в имени файла; вкладка «Сохранённые» с иерархией папок
- Групповые операции по флажкам: отдельные файлы или один общий `.reg`
- Экспорт в `.bat` (`NO-…` — обычное открытие, `NW-…` — новое окно)

### Важно
- Файлы не имеют цифровой подписи: SmartScreen или антивирус могут показать предупреждение.
- Разработка и проверка велись в основном в Wine; на реальных Windows 7–10 проверено ограниченно. Об ошибках сообщайте в Issues, приложив последние строки `keyshelf.log`.

## KeyShelf v0.2 (English)

Portable Windows 7–10 tool: registry key bookmarks, regedit jump (also in a separate window via `/m`), saving keys to `.reg`, `.bat` export.
Files: `KeyShelf_x64.exe` (64-bit), `KeyShelf_x86.exe` (32-bit); checksums in `SHA256SUMS.txt`.
The executables are unsigned (SmartScreen/antivirus may warn). Mostly tested under Wine; limited testing on real Windows. Please report problems in Issues with the last lines of `keyshelf.log`.
