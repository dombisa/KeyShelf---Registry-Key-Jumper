## Key Shelf Reg Jumper v0.4

Файлы: `KeyShelfRegJumper_x64.exe` — для 64-битной Windows, `KeyShelfRegJumper_x86.exe` — для 32-битной. Контрольные суммы — в `SHA256SUMS.txt`.

### Новое
- **Наблюдение за реестром онлайн** (вкладка «Наблюдение»): выбираете ветки (из закладок, целые разделы или свои), и каждое изменение — добавлено, удалено, изменено, с блоками «было / стало» — появляется в списке и записывается в лог наблюдения (папка `Watch`).
- **Взять ветку из открытого regedit** (`Ctrl+G`): путь текущей ветки берётся из окна regedit, затем её можно добавить в закладки, сохранить в `.reg`, использовать в снимке для сравнения, экспортировать в `.bat` или поставить на наблюдение. Запасной путь: «Копировать имя раздела» в regedit и та же команда.
- **Единый файл настроек и закладок** `keyshelf.cfg` вместо `keyshelf.ini` + `keyshelf.ksl`. При первом запуске настройки и закладки переносятся автоматически, старые файлы остаются как `.bak`.
- Режимы командной строки `/watch` и `/probe` (самопроверка).

### Важно
- Наблюдение за целым разделом реестра создаёт заметную нагрузку; для точечного слежения выбирайте конкретные ветки. Программа показывает, что изменилось, но не какой процесс это сделал.
- Чтение ветки из окна regedit проверено ограниченно (regedit часто запущен от администратора, а программа без этих прав); если не сработало, используйте «Копировать имя раздела».
- Файлы не имеют цифровой подписи (SmartScreen или антивирус могут показать предупреждение). Разработка и проверка велись в основном в Wine; на реальных Windows 7–10 проверено ограниченно. Об ошибках сообщайте в Issues, приложив последние строки `keyshelf.log`.

## Key Shelf Reg Jumper v0.4 (English)

**New:** live registry watching (changes with "was / now" blocks in a list and in a log under `Watch`), "take the current key from an open regedit" (`Ctrl+G`, clipboard fallback), a single config file `keyshelf.cfg` instead of `keyshelf.ini` + `keyshelf.ksl` (automatic migration, old files kept as `.bak`), `/watch` and `/probe` command-line modes.
Files: `KeyShelfRegJumper_x64.exe` (64-bit), `KeyShelfRegJumper_x86.exe` (32-bit), checksums in `SHA256SUMS.txt`. Unsigned executables; mostly tested under Wine, limited testing on real Windows. It shows what changed, not which process changed it.
